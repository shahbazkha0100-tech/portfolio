# Shahbaz Khan — Digital Marketing Portfolio

A responsive, static portfolio website for Shahbaz Khan, targeting prospective digital marketing clients in Pakistan.

## Included
- `index.html` — page structure, SEO metadata, social links, and Person structured data
- `styles.css` — responsive dark navy / blue / purple design
- `script.js` — mobile navigation, service pre-selection, and inquiry email draft
- `assets/` — place your own portrait, project screenshots, and optimized images here

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local static server (recommended).
3. Edit copy and placeholders before publishing.

## Before publishing
- Replace `https://example.com/` in the canonical link with the real portfolio URL.
- Add a real portrait and replace sample project illustrations/cards with genuine work.
- Add verified credentials, client testimonials, and case study results only when available.
- The contact form opens a prefilled email draft; it is not a server-side form. For production, connect a form provider or backend and test submission.
- Add a privacy policy if you collect personal information.
- Test mobile layout, links, metadata, accessibility, and page speed.
- Submit the sitemap in Google Search Console after deployment.

## Deploy
Upload the extracted files to your hosting provider's public web directory. Keep `index.html`, `styles.css`, and `script.js` in the same directory.
